## 🔧 Troubleshooting

Most issues are easy to fix. Try these simple steps:

### Files-Companion won't open

1. Right-click the icon and choose **"Run as administrator"**.
2. Restart your computer, then try again.
3. Re-download the setup file and re-install.

### Win+E isn't routing to the Files app

1. Make sure the Files app is installed from the Microsoft Store.
2. Open Files-Companion settings and toggle smart routing off, then on again.
3. Restart Files-Companion.

### Recycle Bin previews aren't showing

1. Check that image previews are enabled in Files-Companion settings.
2. Only image files (PNG, JPG, GIF, BMP) show previews – other file types won't.
3. Restart your computer if previews still don't appear.

### I see a Windows security warning

This is standard for new software. Click **"More info"** and then **"Run anyway"**. This only appears the first time you run the program.
